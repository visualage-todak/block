# 인스타 계정 점검표

각 항목에 ✅ / ❌ 표시. ❌ 항목부터 위에서 아래 순서로 고친다.

## 1. 기본 설정 (5분)
- [ ] 프로페셔널 계정(크리에이터나 비즈니스)으로 전환 — 인사이트를 보려면 필수
- [ ] 공개 계정
- [ ] 카테고리 설정
- [ ] 연락 버튼과 링크 설정 (게임 링크, 링크트리 등)

## 2. 프로필 (첫인상 3초)
- [ ] 프로필 사진: 작게 봐도 알아볼 수 있는 얼굴이나 로고
- [ ] 이름 칸에 검색 키워드 포함 (예: "그림책 벽돌깨기 | 아이 놀이")
- [ ] 아이디: 짧고 발음하기 쉬움, 숫자·밑줄 최소
- [ ] 소개글 3줄 공식
  1. 누구를 위한 계정인지
  2. 팔로우하면 무엇을 얻는지
  3. 행동 유도 + 링크
- [ ] 첫 화면 9개 게시물만 봐도 계정 주제가 바로 보임
- [ ] 대표 게시물 1~3개 고정
- [ ] 하이라이트 3~5개 (소개 / 사용법 / 후기 / 이벤트)

## 3. 콘텐츠
- [ ] 계정 주제가 하나로 일관됨 (관련 없는 게시물이 30% 미만)
- [ ] 최근 30일 동안 릴스 비중 50% 이상
- [ ] 모든 릴스의 첫 1초에 화면 텍스트 훅이 있음
- [ ] 자막 있음
- [ ] 릴스 길이 7~30초
- [ ] 캡션 첫 줄 125자 안쪽, 행동 유도는 하나만
- [ ] 해시태그 3~5개, 매번 같은 묶음 복사 금지
- [ ] 워터마크 있는 영상(다른 앱 로고) 재업로드 없음

## 4. 운영
- [ ] 주 3~5회, 비슷한 시간대에 업로드
- [ ] 게시 후 1시간 안에 댓글에 답함
- [ ] 스토리 주 3회 이상 (투표·질문 스티커 활용)
- [ ] 같은 분야 계정에 진심 담긴 댓글 하루 5~10개

## 5. 계정 건강 상태
- [ ] 설정 → 계정 상태: 위반 사항 없음
- [ ] 추천 대상 자격: "추천 가능" 상태
- [ ] 팔로워·좋아요 구매, 자동 팔로우 앱 사용 이력 없음
- [ ] 저작권 음원 경고 없음

## 6. 숫자로 보는 진단 (최근 게시물 5~10개 평균)
| 지표 | 계산 | 낮음 | 보통 | 좋음 |
|---|---|---|---|---|
| 저장률 | 저장 ÷ 도달 | 1% 미만 | 1~2% | 2% 이상 |
| 공유률 | 공유 ÷ 도달 | 0.5% 미만 | 0.5~1% | 1% 이상 |
| 참여율 | (좋아요+댓글+저장+공유) ÷ 도달 | 3% 미만 | 3~6% | 6% 이상 |
| 비팔로워 도달 비율 | 인사이트에서 확인 | 30% 미만 | 30~60% | 60% 이상 |

(위 기준은 대략적인 출발점이다. 내 계정 평균과 비교하는 것이 더 정확하다.)

### 숫자가 낮을 때 고칠 곳
- 비팔로워 도달이 낮음 → 훅이 약하거나 릴스가 적음. 첫 1초 텍스트를 바꾼다.
- 도달은 높은데 저장·공유가 낮음 → 내용이 가볍다. 정보형(저장)이나 공감형(공유)을 강화한다.
- 참여는 좋은데 팔로우 유입이 적음 → 프로필 소개글과 첫 화면 9개를 손본다.
- 전체적으로 갑자기 떨어짐 → 계정 상태 메뉴에서 위반 사항이나 음원 문제를 확인한다.
