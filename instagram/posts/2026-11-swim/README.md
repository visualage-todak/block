# 게시물: 돌봄 이야기 ③ — 도서관 바닥에 누운 아이들 (캐러셀 5장 + 릴스)

## 진단 (원본 캡션)
- 좋은 점: "놀고, 선택하고, 쉬어 가는" 메시지가 분명하다. 1·2편과 이어진다.
- 고칠 점
  1. 첫 줄 "아이들은 돌봄 속에서 스스로 자랍니다"는 결론이라 궁금증이 없다
  2. 행동 유도가 없다
  3. `#아이들의일상` `#놀이와성장`은 너무 넓다 → `#마을돌봄` `#경기도작은도서관`으로
  4. 사진 ①의 자주색 옷을 입은 사람 얼굴이 가려지지 않았다 → 동의 확인 또는 가림 필요

## 훅 10개
| 번호 | 화면 글자 | 방식 |
|---|---|---|
| 1 | 도서관 바닥에 누운 아이들, 괜찮을까요? | 질문 |
| 2 | 아무것도 안 해도 괜찮은 곳 | 반전 |
| 3 | 오늘 아이들이 고른 것은 '쉼'이었습니다 | 경험 |
| 4 | 도서관에서 누워도 혼나지 않는 이유 | 궁금증 |
| 5 | 정해진 활동이 없는 날의 오후 | 장소 |
| 6 | 흔들리는 판 위의 아이, 끝까지 버틸까요? | 서스펜스 |
| 7 | 오목 한 판에서 배운 것 | 궁금증 |
| 8 | '쉬는 것도 배움'이라고 하면 믿으시겠어요? | 질문 |
| 9 | 마지막 장에 답이 있습니다 | 끝까지 보기 |
| 10 | 돌봄 = 바쁘게 시키는 것? | 흔한 오해 |

**추천: 1번.** 도서관과 누운 아이들이 낯선 조합이라 멈춰 보게 되고, 답("네, 괜찮습니다")이 마지막 장에 있다.

## 완성 캡션
```
도서관 바닥에 누운 아이들, 괜찮을까요?

친구와 머리를 맞대고 오목을 두고,
흔들리는 판 위에서 새로운 것에 도전하고,
때로는 바닥에 누워 쉬어 가는 아이들.

정해진 활동이 없어도
아이들은 저마다의 방식으로 하루를 채워 갑니다.

네, 괜찮습니다.
쉬어 가는 것도 아이가 스스로 고른 하루니까요.

토닥토닥의 돌봄은 아이들이 마음껏 놀고, 선택하고,
쉬어 갈 수 있는 시간을 지켜 주는 일입니다. 💚

👉 아이들에게 쉼이 필요하다고 생각하시면, 이 글을 한 분께 공유해 주세요.

#토닥토닥그림책도서관 #작은도서관돌봄 #마을돌봄 #경기도작은도서관 #여주
```
지원사업 해시태그(#경기도작은도서관돌봄지원사업)를 꼭 넣어야 한다면 `#경기도작은도서관` 자리에 넣는다.
릴스에서는 "이 글을" → "이 영상을".
