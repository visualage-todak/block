# 인스타 바이럴 플레이북

## 바이럴의 핵심 지표
요즘 인스타 추천은 **공유(DM 전송) > 저장 > 시청 유지 > 댓글 > 좋아요** 순으로 무게가 실리는 경향이 있다.
"좋아요 받을 콘텐츠"보다 **"친구한테 보내고 싶은 / 나중에 다시 볼 콘텐츠"**를 만든다.

## 7가지 원칙
1. **첫 1초 훅** — 화면 텍스트로 결론이나 궁금증을 먼저 던진다.
2. **짧게, 반복되게** — 릴스 7~15초. 끝이 처음과 이어지면 루프 재생이 늘어난다.
3. **하나의 메시지** — 한 게시물 = 한 가지 정보/감정.
4. **자막 필수** — 소리 끄고 보는 사람이 많다.
5. **저장 유도형 정보** — 리스트, 꿀팁, 전후 비교, 체크리스트는 캐러셀로.
6. **공유 유도형 공감** — "이거 너잖아", "우리 애도 이래요" 류의 공감.
7. **꾸준함** — 주 3~5회, 비슷한 시간대. 게시 후 1시간 안에 댓글에 답한다.

## 훅 문구 템플릿
- "○○ 하는 사람 99%가 모르는 것"
- "이거 모르고 ○○ 하지 마세요"
- "3초만에 ○○ 하는 법"
- "○○ 전 vs 후"
- "저장해두면 언젠가 쓸 ○○ 리스트"
- "우리 아이가 ○○ 했을 때 반응 😂"
- "아무도 안 알려준 ○○ 꿀팁"

## 캡션 구조
```
[첫 줄: 훅 반복 또는 궁금증 — 125자 안쪽]

[본문: 2~4줄, 줄바꿈 넉넉히]

[행동 유도: 하나만]
👉 나중에 보려면 저장
👉 필요한 친구 태그
👉 댓글로 "○○" 남기면 보내드려요

#대형태그 #중형태그 #중형태그 #니치태그 #니치태그
```

## 해시태그 전략
- 3~5개면 충분. 콘텐츠와 정확히 맞는 것만.
- 대형(100만+) 1개, 중형(1만~100만) 2개, 니치(1만 이하) 2개.
- 매번 같은 30개 복붙은 피한다.

## 업로드 시간 (출발점, 내 데이터로 조정)
- 평일 점심 12~13시, 저녁 20~22시
- 주말 오전 10~11시
- 인사이트의 "팔로워 활동 시간"이 가장 정확하다.

## 포맷 아이디어 (그림책 벽돌깨기 게임 홍보 예시)
| 포맷 | 훅 | 행동 유도 |
|---|---|---|
| 릴스 | "7살이 그림책 벽돌깨기 처음 해본 반응" | 공유 |
| 릴스 | "벽돌 깰 때마다 그림책이 나온다고?" | 댓글 |
| 캐러셀 | "아이랑 5분 놀이 — 화면 보며 책 읽기 습관 만드는 법" | 저장 |
| 스토리 | "몇 라운드까지 깼어요?" 투표/질문 스티커 | 참여 |
| 릴스 | "엄마 vs 아이 점수 대결" | 친구 태그 |
