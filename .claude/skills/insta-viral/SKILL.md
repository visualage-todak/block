# 인스타 바이럴 스킬

인스타그램 콘텐츠를 기획하고, 만들고, 기록·분석해 다음 콘텐츠에 반영하는 작업 흐름.
관리 파일은 저장소의 `instagram/` 폴더에 있다.

| 파일 | 용도 |
|---|---|
| `instagram/calendar.md` | 주간 업로드 계획 (아이디어 → 제작 → 예약 → 게시) |
| `instagram/performance.csv` | 게시물별 성과 기록 |
| `instagram/ideas.md` | 아이디어 백로그 |
| `instagram/playbook.md` | 훅·캡션·해시태그 템플릿과 바이럴 원칙 |

## 1. 기획 요청을 받으면

1. `instagram/performance.csv`에서 저장·공유 비율이 높았던 게시물의 공통점을 먼저 찾는다.
2. `instagram/playbook.md`의 포맷 중 하나를 골라 아이디어 3개를 제안한다. 각각:
   - 포맷 (릴스 / 캐러셀 / 스토리)
   - 첫 1~3초 훅 (화면 텍스트 + 말)
   - 구성 (컷 단위, 릴스는 7~15초 권장)
   - 캡션 초안 (첫 줄은 125자 안쪽, 마지막은 행동 유도)
   - 해시태그 3~5개 (대형 1 · 중형 2 · 니치 2)
   - 행동 유도: 저장 / 공유 / 댓글 중 하나만
3. 사용자가 고른 아이디어를 `instagram/calendar.md`에 날짜와 함께 추가한다.

## 2. 성과 기록 요청을 받으면

- 사용자가 준 수치(조회, 도달, 좋아요, 댓글, 저장, 공유, 팔로우 유입)를 `performance.csv`에 한 줄 추가한다.
- 다음 지표를 계산해 알려준다:
  - 저장률 = 저장 / 도달
  - 공유률 = 공유 / 도달
  - 참여율 = (좋아요+댓글+저장+공유) / 도달
- 기준: 공유률 1% 이상 또는 저장률 2% 이상이면 "확산형" → 같은 포맷으로 변형 2개를 아이디어 백로그에 추가.
- 캘린더의 해당 항목 상태를 `게시`로 바꾼다.

## 3. 주간 리뷰 요청을 받으면

- 지난 7일 게시물을 성과순으로 정리, 상위/하위 각 1개의 이유를 훅·포맷·업로드 시간 기준으로 분석.
- 다음 주 캘린더 초안을 작성 (주 3~5회, 릴스 비중 60% 이상).

## 원칙

- 수치를 지어내지 않는다. 사용자가 준 데이터만 쓴다.
- 인스타 알고리즘에 대한 단정적 주장은 피하고 "경향"으로 말한다.
- 다른 크리에이터의 콘텐츠를 그대로 베끼지 않는다. 포맷만 빌린다.
- 팔로워·좋아요 구매, 자동 팔로우 툴 등 약관 위반 방법은 권하지 않는다.
